# PB-RAT-01 Unauthorized Remote Access Tool

Owner: Incident Response. Severity guidance and steps below are mandatory for this alert category.

## Applies to
AnyDesk, ScreenConnect, RustDesk, or user-installed TeamViewer on non-helpdesk hosts; help-desk impersonation calls.

## Response steps
- Isolate the host and end the session.
- Call the user on the directory number, not the number that called them.
- For Finance users, ask Treasury to freeze payments initiated in the last 24 hours.
- Block the tool's domains at the proxy.

## Additional guidance
Warn all staff about the fake IT-support calls through the security awareness channel.
